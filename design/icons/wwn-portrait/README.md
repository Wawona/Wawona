original grayscale portrait, reconstructed WWN lettering, and a flat amber
medallion. The portrait raster is extracted from the generated concept;
its facial details remain raster artwork. The background and letter paths
are kept as editable SVG sources alongside their transparent PNG exports.

settings, not effects baked into the amber layer. The package passes the
shared JSON schema and renders with Apple's installed Icon Composer 1.6.

no dedicated HDR emission layer, since the supplied portrait contains no
