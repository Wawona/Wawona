# Carved W! redwood icon draft

The reference is reduced to a navy field, one redwood silhouette, three broad
bark bands, and a geometric W! with a separate exclamation mark. The letter
has a distinct angular design. There are no sparks or painted wood textures.

The W! is carved through the wood face. Both the trunk and bark layers have
matching transparent cutouts. A separate dark inner wall sits behind the wood;
the luminous interior is recessed with an inset and a small down/right offset.
The simple geometry keeps the carving readable at icon sizes. Native Liquid
Glass is enabled on the wood face and HDR interior, with specular highlights,
subtle translucency, and restrained blur on the wood. The dark inner wall
remains opaque so the carving reads as a recess. These effects are Composer
settings, separate from the artwork and HDR light data.

## Dedicated HDR layer

Wawona.icon/Assets/interior-hdr.exr is a separate 1024-pixel, 32-bit
floating-point RGBA OpenEXR image, encoded as scene-linear Rec.709 / D65 with
straight alpha. SDR reference white is 1.0. Red reaches 4.0, two stops above
reference white. The HDR data was reopened and its values verified.

The installed Apple Icon Composer 1.6 renderer successfully reads this EXR
inside the layered package. HDR display output and installed-device brightness
have not been measured. The supplied PNG previews are SDR renditions.

interior-sdr.png is a gold companion for SDR-only workflows. hdr-layer.json
records the HDR encoding and headroom. flat.png is an opaque 1024-pixel SDR
artwork export without an icon mask. Source SVGs and the carving mask remain
editable. System edge lighting in native previews is generated by Apple.

## Validation and integration

The compose-app-icon schema and asset cross-check passed, followed by Apple's
ictool renders of light, dark, tinted, watch, and 64-pixel appearances. The
package contains three groups: carved wood face, carving depth, and HDR tree
interior, ordered front-to-back.

This is a reviewable draft. Production catalogs and Android assets have not
been replaced. When the design is accepted, update all product icon sources
together to avoid inconsistent branding across platforms.

Design basis: https://developer.apple.com/design/human-interface-guidelines/app-icons
