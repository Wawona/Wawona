# WWN stacked monogram

Revision of the horizontal WWN draft. User direction: a square composition,
unique rounded lettering, and letters almost stacked on top of each other.

Custom geometric letterforms use rounded terminals, curved valleys, and
near-superimposition with a small diagonal offset. Three independent native
Liquid Glass planes make the overlaps visible. The dedicated internal-light
OpenEXR remains float32, scene-linear Rec.709/D65 with straight alpha and a
verified peak channel value of 2.0 (reference white 1.0).

Wawona.icon is the editable native package. logo.svg is the single-color
identity. Separate SVGs and PNGs preserve each letter for further refinement.

Validated with the shared compose-app-icon schema and rendered with native
Icon Composer 1.6. OS 27-specific material rendering is not verified here.
PNG previews are SDR and do not establish HDR display brightness.

This is a design draft. Product asset catalogs are unchanged.
