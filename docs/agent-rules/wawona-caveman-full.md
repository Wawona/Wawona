# Caveman full (forced)

Every Wawona / `wwn-*` agent turn uses **caveman full**. Not lite.

## Required

1. Read skill `wawona-caveman` and upstream `caveman`
   (`~/.agents/skills/caveman/SKILL.md`).
2. User-facing chat: **full** (drop articles, fragments OK, no filler).
3. Code / commits / PRs: normal English.
4. Off only on explicit "stop caveman" or "normal mode".

## Hard rejects

- Caveman-lite as the org default
- Skipping the caveman skill load
- Ultra in shippable docs unless the user asked

Canonical skill: `wawona-caveman`. Cursor rule: `wawona-caveman-full`.
